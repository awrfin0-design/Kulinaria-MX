# HTML preview vs the live Shopify theme

`preview/index.html` is generated by running the **same Liquid files** (layout, sections, snippets, JSON templates) and the **same CSS and JS** that go to Shopify, with sample data. What can differ, and why:

| Area | Preview | Shopify |
|---|---|---|
| Markup, copy, layout, animations, funnel, menu, theme/language logic | identical | identical |
| Languages | both embedded, switched with a reload (like Shopify serving /en/) | Shopify Languages / Markets |
| Product data, prices, images | sample data (`scripts/render/mock.mjs`) | your products and their media |
| Photos and videos | embedded in the single file (served from memory) | files in `assets/` served by Shopify's CDN |
| Cart, checkout, login, forms | simulated (no server) | real Shopify cart, checkout and customer accounts |
| Menu (burger) | the nested menu of the mock | your Navigation menu, or the built-in complete sitemap when none exists |

Practical rules to keep them identical: change the theme files, never `preview/index.html`; rebuild with `node scripts/render/render.mjs`; the test suite (`node scripts/render/test.mjs`) runs against the generated preview. After uploading to Shopify, create the pages, collections, navigation and products with `backend/shopify/setup.mjs` and `seed-dishes.mjs`, and set Customer accounts to **Classic** (Settings → Customer accounts) so the theme's login, registration and account pages are used.
